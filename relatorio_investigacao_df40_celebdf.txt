B. Comparacao de integridade (SHA256) em 20 imagens com mesmo caminho relativo:
Comando executado:
  .venv/bin/python -c '
  from pathlib import Path
  import hashlib

  root = Path("/media/ssd2/lucas.ocunha/datasets/df40_extracted")
  cdf_root = root / "cdf/frames"
  technique_paths = {
      "blendface": root / "blendface/cdf/frames",
      "faceswap": root / "faceswap/cdf/frames",
      "mobileswap": root / "mobileswap/cdf/Youtu_Pangu_Security/public/youtu-pangu-public/zhiyuanyan/deepfakes_detection_datasets/DF40/mobileswap/cdf/frames",
      "uniface": root / "uniface/cdf/frames",
  }

  common_subdirs = set(d.name for d in (root / "uniface/cdf/frames").iterdir() if d.is_dir())
  sample_images = []
  for sub in sorted(common_subdirs):
      sub_path = cdf_root / sub
      for img in sorted(list(sub_path.glob("*.png"))):
          rel = Path(sub) / img.name
          if all((p / rel).exists() for p in technique_paths.values()):
              sample_images.append(rel)
              break
      if len(sample_images) == 20:
          break

  def get_sha256(filepath):
      h = hashlib.sha256()
      with open(filepath, "rb") as f:
          while chunk := f.read(65536):
              h.update(chunk)
      return h.hexdigest()

  matches = {tech: 0 for tech in technique_paths}
  for i, rel in enumerate(sample_images):
      cdf_sha = get_sha256(cdf_root / rel)
      parts = [f"{i+1:02d}. {rel}"]
      for tech, t_root in technique_paths.items():
          match = (get_sha256(t_root / rel) == cdf_sha)
          if match:
              matches[tech] += 1
          parts.append(f"{tech}:{'MATCH' if match else 'DIFF'}")
      print(" | ".join(parts))

  print("\nResumo SHA256 matches com cdf/frames raiz:")
  for tech, count in matches.items():
      print(f"  {tech}: {count}/20")
  '

2.2. Base de origem de cada conjunto de imagens reais
-----------------------------------------------------
1. whichfaceisreal/real:
   - Resolucao: 1024x1024 JPEG
   - Padrao dos nomes: 00000.jpeg a 00999.jpeg (5 digitos sequenciais)
   - Base de origem: FFHQ (Flickr-Faces-HQ)
   - Evidencia: As imagens reais da plataforma WhichFaceIsReal sao extraidas diretamente
     do dataset FFHQ em sua resolucao nativa de 1024x1024.

2. CollabDiff/real:
   - Resolucao: 178x218 JPEG
   - Padrao dos nomes: 000265.jpg, 000648.jpg (6 digitos)
   - Base de origem: CelebA
   - Evidencia: Resolucao canonica estrita do CelebA (178x218 pixels) e indices numericos
     de 6 digitos identicos a lista oficial do CelebA.

3. styleclip/real:
   - Resolucao: 178x218 JPEG
   - Padrao dos nomes: 000055.jpg, 000186.jpg (6 digitos)
   - Base de origem: CelebA
   - Evidencia: Resolucao canonica de 178x218 pixels e indices numericos de 6 digitos do CelebA.

4. MidJourney/real:
   - Resolucao: 256x256 JPEG
   - Padrao dos nomes: 00005.jpg a 69896.jpg (5 digitos)
   - Base de origem: FFHQ (Flickr-Faces-HQ)
   - Evidencia: Intervalo de 5 digitos no espaco de 0 a 69.999 correspondente as 70.000 imagens
     do dataset FFHQ, redimensionadas para 256x256.

5. starganv2/real:
   - Resolucao: 256x256 JPEG
   - Padrao dos nomes: 0.jpg, 1.jpg, 10.jpg
   - Base de origem: CelebA-HQ
   - Evidencia: Nomenclatura e resolucao geradas pelo script oficial de download do StarGAN v2
     (clovaai/stargan-v2) para o subconjunto CelebA-HQ a 256x256.

6. heygen_new/real:
   - Resolucao: 512x512 PNG
   - Padrao dos nomes: Clip+<YouTube_ID>+P0+C1+F<frame_range>/<frame>.png
   - Base de origem: VFHQ (Video Face High Quality)
   - Evidencia: Estrutura de subdiretorio Clip+-1Jouc19Ixo+P0+C1+F4196-4320 caracteristica
     do benchmark VFHQ (recortes faciais de alta definicao de videos do YouTube alinhados a 512x512).
